# Better Fox Trot Brew

[English](README.md) | **简体中文**

适用于 **Minecraft 1.20.1 / Forge**。基于 [Fox Trot Brew（狐步酿香）](https://github.com/WitherRedstone/Fox-Trot-Brew) 的 `1.20.1-forge` 分支开发，改进车万女仆操作森罗物语：酒馆果盆的逻辑。

## 版本支持

目前 Better Fox Trot Brew **仅支持 Minecraft 1.20.1 / Forge**。仓库中的 `1.21.1-neoforge` 分支继承自上游项目，暂时保留作为参考；本项目的功能改进**尚未移植到该分支，也未在该版本上测试**。保留此分支不代表已经支持 NeoForge。

如果你希望适配 Minecraft 1.21.1 / NeoForge 或其他版本，欢迎[提交 Issue](https://github.com/fatekingsama/better-fox-trot-brew/issues)，注明 Minecraft 版本、模组加载器及使用需求。我们会根据反馈考虑后续适配优先级，目前暂无明确的发布时间。

## 0.1.2 功能与使用

给女仆选择 **「果盆酿造（改进版）」** 任务，在她的背包、主手或副手放入葡萄与空桶，并为果汁桶留出空间。

- **自动补料**：果盆原料槽为空时，从背包或双手补充原料，检查配方、果汁类型和槽位容量。
- **自动踩汁**：有可加工的原料、果汁还有足够空间时进行踩踏。只有残余果汁而没有可用原料时，不会一直原地跳跃。
- **优先收桶**：优先收取满汁果盆，即使盆中已没有葡萄。收桶、补料可以从盆旁可行走的位置接近，踩踏还会检查盆上方的落脚点。
- **物品回收**：剩余原料和装好的果汁桶优先放进背包，再尝试可用的手部槽位。遇到意外的物品放入失败，会把剩余物品掉落在女仆身边，避免丢失。
- **轮换与超时**：单次访问最多 12 秒；连续 4 秒没有原料或果汁变化则结束访问。完成后冷却 2 秒，卡住或不可达的盆冷却 5 秒；前往果盆超过 10 秒则放弃本次寻路。
- **工作范围**：遵守女仆的活动范围，不主动加载尚未加载的区块。
- **空闲行为**：没有可做的工作时保留当前任务，沿用女仆默认的空闲移动行为。

本版不负责采收葡萄藤，也不从外部箱子存取物品。多只女仆之间尚未实现果盆占用预约；实际交互由游戏服务端依次执行。

## 安装与旧存档

模组 ID 为 `better_fox_trot_brew`，这是独立分支，不会覆盖原版的任务 ID。

**请勿与原版 Fox Trot Brew 同时加载**，两者仍使用相同的 Java 类名。请先备份并移除原版 JAR，再安装本模组，并为原来的工作女仆重新选择「果盆酿造（改进版）」任务。测试前请备份存档。

构建项目不会自动把模组安装进游戏。

## 构建与检查

使用 Java 17 工具链和项目自带的 Gradle 8.8 Wrapper。在项目目录执行：

```powershell
.\gradlew.bat build
```

依赖已经缓存时，可以离线构建；如使用自定义 Gradle 用户目录，请通过 `--gradle-user-home` 指定：

```powershell
.\gradlew.bat --offline build
```

`check` 包含 `policyRegression`，运行 10 项独立的决策与超时检查，无需额外的测试框架。

玩家已确认 0.1.2 在修复手持空桶识别后恢复工作。这属于初步游戏验证，并不代表所有验收场景均已通过：寻路、跳跃、物品转移、果汁显示刷新和多女仆协作不在上述独立逻辑检查的覆盖范围内。

### 游戏内验收场景

1. 两个果盆：第一个放不足 8 个葡萄，第二个有可用原料。第一个踩完后，女仆应离开并处理其他果盆。
2. 满汁但没有葡萄的果盆：消耗一个空桶，获得一个果汁桶，果汁减少恰好 1000 mB。
3. 背包其他位置已满，只有一个单独的空桶：装好的果汁桶可以使用空桶腾出的槽位。
4. 没有空桶，或空桶成组且没有成品空间：不丢失果汁和桶，转而处理其他可工作的盆。
5. 空果盆，女仆背包有葡萄：正常补料并踩踏，不重复生成物品。
6. 盆内有残留果汁，背包只有不兼容的原料：不混合果汁，不无限跳跃。
7. 果盆被障碍挡住：超时后选择其他果盆。
8. 多个可工作的盆：单次访问有时间限制，避免长期只处理同一个盆。
9. 分别把空桶放在主手、副手：两种情况都应能收汁，成品优先放进背包。
